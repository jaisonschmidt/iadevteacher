# Assessments

Examiner stores every completed assessment attempt here. Records are append-only learning evidence and must not be overwritten by later attempts.

Expected structure:

```text
assessments/
└── module-01-module-name/
    └── step-01-01-step-name/
        ├── 2026-09-02-attempt-01.md
        └── 2026-09-05-attempt-02.md
```

Full questions and answers stay here; `docs/PROGRESS.md` contains only links and concise results.
